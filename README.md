# Inter-Tech Costa Rica — portada principal

Sitio estático listo para publicar como nueva página principal.

## Estructura

- `index.html`: contenido y estructura de la portada.
- `styles.css`: diseño responsive para escritorio y móvil.
- `script.js`: menú móvil y animaciones suaves al desplazarse.
- `assets/`: imágenes optimizadas para la narrativa visual.

La tienda actual se conserva como página secundaria y se abre desde **Ver tienda** y **Tienda y catálogo**.

## Vista local

Abra una terminal en esta carpeta y ejecute:

```powershell
python -m http.server 4173
```

Luego visite `http://127.0.0.1:4173`.

## Publicación sugerida

Publicar esta carpeta en el repositorio principal de GitHub Pages y mantener el catálogo existente en `/page/`. Antes de publicar, conviene confirmar que los proyectos descritos como Uvita y Manuel Antonio pueden presentarse públicamente como trabajos reales; las imágenes actuales son recreaciones editoriales generadas para el sitio.
